## Prefer to skip the terminal entirely?

There is now a **Claude Code Desktop app** with a normal window, buttons, and no terminal at all. If you would rather not touch the terminal, that is a completely valid door in.

<Callout type="tip" title="The no terminal option">
  Download the{" "}
  <a href="https://claude.com/download" target="_blank" rel="noopener noreferrer">Desktop app</a>{" "}
  for macOS or Windows, sign in, and you can start giving Claude Code instructions right away. You can always come back and learn the terminal later. The rest of this lesson covers the terminal path, which is worth knowing.
</Callout>

## What a terminal is

**Terminal.** A window where you type commands instead of clicking buttons. It comes built into your computer. Commands can install software, change files, delete data, or send information over the network. Read a command before running it, use the official source, and ask for an explanation if any part is unclear. Closing the window does not undo a command that has already run.

## Step 2. Install Claude Code

The commands below download and execute Anthropic's installer. Check them against the [official installation guide](https://code.claude.com/docs/en/setup), then use the one for your system. The native installer does not require Node.js and normally updates itself in the background.

<PlatformTabs
  mac={
    <Terminal command="curl -fsSL https://claude.ai/install.sh | bash" />
  }
  windows={
    <Terminal
      title="PowerShell"
      prompt=">"
      command="irm https://claude.ai/install.ps1 | iex"
    />
  }
  linux={
    <Terminal command="curl -fsSL https://claude.ai/install.sh | bash" />
  }
/>

Give it a moment. When the cursor comes back and stops printing, it is done.

<Callout type="note" title="Rather use npm?">
  If you already have Node.js version 22 or newer, you can install with{" "}
  <code>npm install -g @anthropic-ai/claude-code@latest</code> instead. Do not add
  <code>sudo</code>. The native installer avoids that Node.js prerequisite and is
  the path used in this lesson.
</Callout>

## Step 3. Check it worked

Type this and press Enter:

<Terminal command="claude --version" output="A version number, followed by (Claude Code)" />

If you see a version number, any recent one, you are good. If instead you see &ldquo;command not found&rdquo;, close the terminal, open a fresh one, and try again. A brand new window picks up the freshly installed tool.

<Callout type="tip" title="A built in doctor">
  Claude Code ships with a self check. If anything feels off, run{" "}
  <code>claude doctor</code> and it tells you what is wrong and how to fix it.
</Callout>

## Step 4. Start it up and sign in

Type:

<Terminal command="claude" />

The first time, it opens your browser to sign in with your Claude account. Follow the prompts. When you land back in the terminal on a friendly welcome screen waiting for your input, you are in.

## If something goes sideways

Start with the [official troubleshooting guide](https://code.claude.com/docs/en/troubleshooting). If you ask for help elsewhere, share the error after removing API keys, tokens, private paths, and other sensitive details.

<Callout type="tip">
  Do not aim for a perfect, tidy setup. Aim for &ldquo;it starts.&rdquo; That is the whole bar for this lesson.
</Callout>
